Putting It All Together

Lesson 007 — A complete multi-service app with Config, Logger, Database, and UserRepo

The dependency graph we'll build

┌─────────┐ │ Config │ (leaf — no deps) └────┬────┘ │ Layer.provide ┌────────┴────────┐ ▼ ▼ ┌─────────┐ ┌──────────┐ │ Logger │ │ Database │ (both need Config) └─────────┘ └────┬─────┘ │ Layer.provideMerge ┌─────┴─────┐ ▼ ▼ (both need Database) ┌─────────┐ ┌──────────┐ │UserRepo │ │OrderRepo │ └─────────┘ └──────────┘ │ │ └─ merge ───┘ │ AppLayer (all closed) │ Effect.provide ▼ program

Step 1: Define all service tags

import { Context, Effect, Exit, Layer, Scope } from "effect"

// ─── Config ───
class Config extends Context.Service<Config, {
  readonly get: Effect.Effect<{
    readonly dbUrl: string
    readonly logLevel: string
  }>
}>()("app/Config") {}

// ─── Logger ───
class Logger extends Context.Service<Logger, {
  readonly info: (msg: string) => Effect.Effect<void>
  readonly error: (msg: string) => Effect.Effect<void>
}>()("app/Logger") {}

// ─── Database (scoped resource) ───
class Database extends Context.Service<Database, {
  readonly query: (sql: string) => Effect.Effect<readonly unknown[]>
}>()("app/Database") {}

// ─── UserRepo ───
class UserRepo extends Context.Service<UserRepo, {
  readonly all: Effect.Effect<readonly unknown[]>
  readonly findById: (id: string) => Effect.Effect<unknown>
}>()("app/UserRepo") {}

Step 2: Build each layer

// ─── ConfigLive ─── (leaf, no deps)
const ConfigLive = Layer.succeed(Config, {
  get: Effect.succeed({
    dbUrl: "postgres://localhost:5432/myapp",
    logLevel: "INFO"
  })
})
// Layer<Config, never, never>

// ─── LoggerLive ─── (needs Config)
const LoggerLive = Layer.effect(Logger,
  Effect.gen(function* () {
    const config = yield* Config
    return {
      info: (msg) =>
        Effect.gen(function* () {
          const { logLevel } = yield* config.get
          if (logLevel === "DEBUG" || logLevel === "INFO")
            console.log(`[INFO] ${msg}`)
        }),
      error: (msg) => console.error(`[ERROR] ${msg}`)
    }
  })
)
// Layer<Logger, never, Config>

// ─── DatabaseLive ─── (needs Config, scoped resource)
const DatabaseLive = Layer.effect(Database,
  Effect.gen(function* () {
    const config = yield* Config
    const { dbUrl } = yield* config.get

    // Acquire a connection WITH cleanup
    const pool = yield* Effect.acquireRelease(
      // acquire: connect to database
      Effect.tryPromise({
        try: () => {
          console.log(`Connecting to ${dbUrl}...`)
          return createConnectionPool(dbUrl)
        },
        catch: (e) => new Error(`DB connection failed: ${e}`)
      }),
      // release: close pool when Scope ends
      (pool, exit) =>
        Exit.match(exit, {
          onSuccess: () =>
            Effect.promise(() => pool.end()),
          onFailure: () =>
            Effect.promise(() => pool.end())
        })
    )

    return {
      query: (sql: string) =>
        Effect.tryPromise(() => pool.query(sql)).pipe(
          Effect.map((result) => result.rows)
        )
    }
  })
)
// Layer<Database, Error, Config>
//                              ^^^^ needs Config

// ─── UserRepoLive ─── (needs Database)
const UserRepoLive = Layer.effect(UserRepo,
  Effect.gen(function* () {
    const db = yield* Database
    return {
      all: db.query("SELECT * FROM users"),
      findById: (id: string) =>
        db.query(`SELECT * FROM users WHERE id = '${id}'`).pipe(
          Effect.map((rows) => rows[0])
        )
    }
  })
)
// Layer<UserRepo, Error, Database>

Step 3: Wire the graph

// Close leaf dependencies first, then combine horizontally

// 1. Logger and Database both need Config — satisfy that
const LoggerWithConfig = LoggerLive.pipe(
  Layer.provide(ConfigLive)
)
// Layer<Logger, Error, never>

const DatabaseWithConfig = DatabaseLive.pipe(
  Layer.provideMerge(ConfigLive)
  //   ^^^^^^^^^^^^^  keep Config in output for later
)
// Layer<Database | Config, Error, never>

// 2. UserRepo needs Database — satisfy it, but keep Database visible
//    (so Config gets shared through the graph)
const UserRepoWithDb = UserRepoLive.pipe(
  Layer.provideMerge(DatabaseWithConfig)
)
// Layer<UserRepo | Database | Config, Error, never>

// 3. Merge everything into the final app layer
const AppLayer = LoggerWithConfig.pipe(
  Layer.merge(UserRepoWithDb)
)
// Layer<Logger | UserRepo | Database | Config, Error, never>
//         ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^  all services present
//                                        all requirements satisfied
Pattern: Use provide when a dependency is only needed by one consumer. Use provideMerge when a dependency is needed by multiple consumers (keeps it visible for downstream sharing). Use merge to combine independent subtrees.

Step 4: Write the program and provide once

const program = Effect.gen(function* () {
  const logger = yield* Logger
  const users = yield* UserRepo

  yield* logger.info("Fetching all users...")
  const allUsers = yield* users.all
  yield* logger.info(`Found ${allUsers.length} users`)

  return allUsers
})
// Effect<readonly unknown[], Error, Logger | UserRepo>
//                                 ^^^^^^^^^^^^^^^^^^^
//                             declares its needs explicitly

const runnable = program.pipe(Effect.provide(AppLayer))
// Effect<readonly unknown[], Error, never>
//                                  ^^^^^ all satisfied!

Effect.runPromise(runnable).then(console.log)

What happens at runtime

Effect.provide(AppLayer) │ ├─ Scope created │ ├─ Build ConfigLive (Layer.succeed → instant) │ ├─ Build LoggerLive (runs generator, captures Config) ├─ Build DatabaseLive (runs generator: acquireRelease registers cleanup) │ │ (pool created, finalizer registered on Scope) │ │ │ └─ Build UserRepoLive (runs generator, captures Database) │ ├─ Run program (Logger + UserRepo + Database all working) │ │ │ ├─ logger.info(...) │ ├─ users.all → db.query(...) → pool.query(...) │ └─ logger.info(...) │ └─ Scope closes │ ├─ pool.end() (release from acquireRelease) └─ All resources freed
