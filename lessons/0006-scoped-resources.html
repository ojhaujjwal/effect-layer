Scoped Resources — Acquire & Clean Up

Lesson 006 — How resources get closed when a layered effect finishes

The question you had

How is a database connection actually closed when a layered effect finishes?

The answer involves one concept you already know (Layer.effect) and one you may not (Scope). Here's how they connect.

The three players

PlayerRole
Scope A lifecycle boundary. Tracks finalizers (cleanup functions). When closed, all finalizers run in reverse order.
Effect.acquireRelease Acquires a resource and registers a cleanup finalizer on the current Scope. Returns an Effect that requires Scope.
Layer.effect The generator inside runs within a Scope (provided by the Layer build process). Any acquireRelease calls inside it register finalizers on that Scope.

class Database extends Context.Service<Database, {
  readonly query: (sql: string) => Effect.Effect<unknown[]>
}>()("Database") {}

const DatabaseLive = Layer.effect(Database,
  Effect.gen(function* () {
    // (1) acquireRelease registers "close" as a finalizer on the current Scope
    const connection = yield* Effect.acquireRelease(
      // acquire
      Effect.tryPromise(() => createConnection("postgres://...")),
      // release — runs when Scope closes
      (conn) => Effect.promise(() => conn.close())
    )

    return {
      query: (sql: string) =>
        Effect.tryPromise(() => connection.query(sql))
    }
  })
)

When Effect.provide(DatabaseLive) runs:

  1. Scope is created — Effect.provide internally calls Layer.build, which requires (and is provided) a Scope.
  2. Layer.effect generator runs — acquires the connection. acquireRelease registers the release callback on the Scope. The connection reference is captured in the returned service closure.
  3. Your program runs — calling connection.query() works because the connection is alive and captured in the closure.
  4. Program finishes — the Scope created in step 1 is closed.
  5. All finalizers run — the Scope walks its finalizer list in LIFO order. conn.close() runs. The connection is released.
No explicit Layer.scoped needed in v4. Just use Effect.acquireRelease inside Layer.effect. The Layer build process automatically provides the Scope, and Effect.provide automatically closes it when done.

acquireRelease signature (v4)

Effect.acquireRelease<A, E, R>(
  acquire: Effect<A, E, R>,
  release: (resource: A, exit: Exit<unknown, unknown>) => Effect<unknown>
): Effect<A, E, R | Scope>
//                      ^^^^^  "I need a Scope to run"

The release function receives the exit value — you can inspect whether the program succeeded or failed when doing cleanup: 

const file = yield* Effect.acquireRelease(
  Effect.sync(() => fs.openSync("data.txt", "w")),
  (handle, exit) =>
    Exit.match(exit, {
      onSuccess: () => Effect.sync(() => fs.closeSync(handle)),
      onFailure: (cause) =>
        Effect.sync(() => {
          fs.closeSync(handle)
          fs.unlinkSync("data.txt") // clean up partial file on failure
        })
    })
)

Where does the Scope come from?

It's provided automatically at two levels:

LevelHow Scope is providedResult type
Layer.build(layer) Requires Scope in R — caller must provide it Effect<Context<ROut>, E, RIn | Scope>
Effect.provide(layer) Creates its own Scope internally, builds the layer, runs the program, then closes the Scope Effect<A, E, never> (Scope requirement satisfied) 
// Layer.build: you control the Scope
Effect.gen(function* () {
  const myScope = yield* Scope.make()
  const context = yield* Layer.build(layer).pipe(
    Scope.provide(myScope)  // provide the Scope
  )
  // ... use context ...
  yield* Scope.close(myScope) // explicitly close — finalizers run
})

// Effect.provide:  Scope is managed for you
program.pipe(Effect.provide(layer))
// Scope created → layer built → program runs → Scope closed automatically

Memoization + Scope

Remember lesson 005: layers are built once and shared. The Scope tracks reference counts. A finalizer only runs when the last consumer of the layer is done — not when the first one finishes. This prevents premature cleanup: 

// DatabaseLive is built ONCE, shared between UserRepo and OrderRepo
const AppLayer = Layer.merge(
  UserRepoLive.pipe(Layer.provideMerge(DatabaseLive)),
  OrderRepoLive.pipe(Layer.provideMerge(DatabaseLive))
)

// Both repos use the same connection pool
// When the program ends → Scope closes → pool is released ONCE
